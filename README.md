# Networking labs

© MOUTASEM-AWAD

Upload the contents of this folder to the root of your public `network` GitHub repository. Keep `lab1` and `lab2` as folders. In Settings → Pages select Deploy from a branch, main, /(root), then Save. The homepage links to both quizzes and the fundamentals guide. The guide has a Print / Save as PDF button.

For future quiz edits, edit the original quiz source, run npm run build there, and copy its dist contents into the corresponding lab folder here. Commit and push this network folder to publish updates.
